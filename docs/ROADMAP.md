# Roadmap

## Completed for the mapped local profile

- [x] Local body decoding, JSAV indexing and original trailer reconstruction.
- [x] Inventory-consistent cash/checking/savings editing and ledger/mirror updates.
- [x] Maintainer-reported retail restoration and save/reload persistence for reductions.
- [x] Experimental container increases and above-2M checking persistence evidence.
- [x] Backup, package, local encryption and return-file verification workflow.
- [x] Standalone read-only compatibility checker and privacy-filtered report.

## Closed testing next

- [ ] Receive selected testers' checker reports, game versions, active character and displayed balances.
- [ ] Expand independent samples across campaign stages, bank tiers, characters, manual/autosave slots.
- [ ] Discover ownership/relationships without fixed inventory indices or observed quantity limits.
- [ ] Corroborate statistical mirrors, global ledgers, cached inactive values and capacity effects.
- [ ] Require per-layout acceptance before enabling writing on newly recognized saves.

## Public editor release gates

- [ ] Resolve private codec/runtime input distribution and licensing.
- [ ] Choose a distribution license and complete dependency/provenance review.
- [ ] Complete Git-history/identity review or publish from a separately approved clean-history snapshot.
- [ ] Prepare reproducible synthetic fixtures, tagged source and artifact checksums.
- [ ] Run a limited closed beta with backup/recovery and save/reload checks.
- [ ] Independently validate an online-only path before advertising no modded console needed for this editor.

No public deadline, universal save support or world-first claim is promised. Restoration remains a deliberate user action.

## Public prerelease update — 2026-11-25

MIT and a clean-history public source snapshot are now approved. The checker is published for read-only reports; the editor remains source-only with private runtime dependencies. A single external Xbox-derived PC test now reports imported-state save/reload persistence. This does not complete broad compatibility, license third-party inputs, or make the experimental writer generally runnable.
