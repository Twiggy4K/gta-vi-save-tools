# Public beta release boundaries

Windows x64 portable decoded editor and source are released under MIT. Node.js 24.22.3 and its license notices are bundled in the portable download. No private saves, account identifiers, credentials, game executable or private codec inputs are bundled.

The public editor changes supported decoded money structures locally. The user manually signs into GarlicSaves for website encoding/encryption, checks a decrypted return, and uses GarlicTransfer for deliberate restoration. Website profile byte order may require its Swap Endian option; follow the guide and never swap routinely. No worker key is required by the public UI.

One controlled PS5-origin save passed website round trip, exact game/account-support comparison, retail PS5 loading and user-reported save/reload persistence. Multiple-console/general-save compatibility remains unproven; unsupported mappings fail closed.

Legacy local-ASAV workshop runtime inputs are still undistributed. The separate 0xSavior Xbox-derived PC import/save/reload report does not establish general cross-platform money editing or retail Xbox support. No world-first claim is made.
