# Public prerelease boundaries

Publication is authorized for this clean-history source snapshot and the runnable read-only checker under MIT. This is not a standalone general-purpose money-editor binary release.

The public repository contains no original research Git history, private saves, account data, runtime configurations, game binaries, executable-derived tables or raw listings. The original research archive remains private. Hosting-account handles and the expressly authorized 0xSavior credit are public; no promise of anonymity is made.

## What works without private inputs

The checker works with already decoded JSAV and supported ZIPs. It does not modify saves, connect to consoles, approve restoration or distribute a decoder. Reports contain gameplay balances; users should review before sharing.

## Experimental source limitations

The workshop still needs private runtime inputs not included here. Its writer targets a mapped profile and has fixed assumptions, including an occupied checking-container bound inferred from that original sample. The cross-platform diagnostic code was a separately verified experiment; the shipping PS5 writer has not silently been promoted to a universal version-2 converter. No general install/download path for those private inputs is supplied.

The reported Xbox-derived PC load/save/reload test concerns one external build and specific samples. Rebuilt-control acceptance and imported-state persistence do not establish Xbox-side money editing, arbitrary PS5-to-Xbox conversion, retail Xbox restoration or support for all PC ports. Online-only container processing for the workshop is also not validated end to end.

Before a later editor release: resolve distributable runtime setup, independently map more layouts, add ownership/capacity checks, and run backed-up acceptance tests with multiple volunteers. No release date is promised.
