# Contributing

This is a public experimental-source repository under MIT. Synthetic-only improvements, privacy-filtered compatibility reports, documentation corrections and independently attributable format observations are welcome through selected testing.

Never attach private saves, PSN account details, keys, executable material or decoded save content to issues or commits. The read-only checker does not authorize editing or restoration. Obtain consent before any private sample transfer.

Run `npm run audit:source` and `npm test` before pushing. Describe evidence and limitations; distinguish source-only tests from private integrations and gameplay reports. Preserve the maintainer's empirical contribution, disclose AI assistance, and attribute external discoveries without importing implementation code under unreviewed licenses.

Contributions must be independently authored or have compatible, documented licensing. Do not submit private game material, executable-derived tables, saves or account data. A change to editor compatibility claims requires new evidence, not only passing synthetic tests.
